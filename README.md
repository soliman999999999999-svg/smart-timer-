# FocusFlow

A 50-minute Pomodoro timer and daily study-hours tracker. Runs entirely in the browser; data is stored in local storage on your device. Installable as an app (PWA) and works offline after the first load.

## Files
- `index.html` - the app
- `manifest.webmanifest` + `sw.js` - make it installable and offline-capable
- `icons/` - app icons

## Publish on GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload all files and the `icons` folder, keeping this structure, to the repository root.
3. Go to **Settings > Pages**. Under "Build and deployment", choose **Deploy from a branch**, select **main** and **/ (root)**, then Save.
4. After a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.

## Install
Open the live link, then use the browser's Install button (Chrome/Edge) or Share > Add to Home Screen (iPhone).
